Old Java Applications

Java Swing and AWT programs recovered from old jars, compiled to JavaScript with TeaVM. Each runs on a small AWT/Swing layer that draws the original windows and widgets in the page.

Play in the browser

  • ClockAnalog or digital clock. Click to switch.Play
  • Flappy BirdSpace to flap, P to pause, R to reset, D for debug view.Play
  • Minesweeper15 x 15 board with MIDI sound. Right-click to flag. Arrow keys move the window.Play
  • NathaNOSA fake desktop with a taskbar and start menu that launches the old Clock build.Play
  • Rubik's Cube 2DClick a square, then W A S D to turn. Mix scrambles the cube.Play
  • Screen SaverGreen circles fill the screen. Moving the mouse closes it.Play
  • Sprite Floaty StarsAnimated stars with five modes. Pick settings and press OK.Play
  • Ultimate Tic-Tac-ToeNine boards; your cell picks your opponent's next board.Play
  • Circle SpawnerBuilds a disk out of many borderless blue windows.Play
  • Stock CheckerEditable ticker list. The quote API is retired, so refresh shows the saved 2016 prices.Play
  • Synthesizer KeyboardOne-octave piano: Z X C V B N M , and S D G H J. Arrows change octave and instrument.Play

Desktop only

  • DinoGamePlays the Chrome dino game by reading screen pixels and pressing Space with java.awt.Robot; a page cannot see or control other windows.
  • WindowsPresses the real Windows key with java.awt.Robot, which a web page cannot do.
  • WindowsEOpens File Explorer windows by pressing Win+E with java.awt.Robot, which a web page cannot do.
